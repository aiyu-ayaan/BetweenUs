What it is

A full communication platform, deployed as microservices

Listen Together

Synchronised YouTube listening inside voice calls with zero media uplink. Browse YouTube in-app, click any thumbnail to play instantly for the call, enjoy automatic voice ducking when talking, and shared queue controls with no host bottleneck.

E2EE Chat & Rich Markdown

End-to-end encrypted messaging with AES-256-GCM. Live markdown preview in the composer, bulleted/numbered lists, inline code & quotes, custom emoji, reactions, replies, and encrypted attachments up to 100 MB.

P2P Voice, Video & Screen Control

Voice and video channels over direct WebRTC mesh without expensive media servers. Includes interactive screen sharing where participants can request and take control with named multi-user cursor overlays.

Remote Desktop, Done Safely

Secure remote machine access with screen viewing, keyboard/mouse control, multi-monitor selection, and clipboard sync — gated by granular per-machine, per-user permission grants and a non-repudiable audit trail.

Microservices & Ingress

Independently deployable NestJS microservices backed by PostgreSQL and Redis. Public traffic enters via Cloudflare Tunnel into an Nginx API Gateway with zero inbound open ports required.

Desktop, Web & Native Android

Modern Electron desktop client with tray integration, identical web client mounted via Vite, and native Kotlin/Jetpack Compose Android app with FCM push notifications and background survivability.

Installation & Setup

Get started with BetweenUs

Install Desktop & Mobile AppsEnd Users

Download pre-built binaries for Windows, macOS, Linux, or Android APK. Connect directly to any self-hosted BetweenUs deployment.

1
Download Desktop Release
Get the latest installer or portable executable (.exe / .AppImage / .dmg) from GitHub Releases.
# Download from https://github.com/aiyu-ayaan/BetweenUs/releases
# Or package locally from source:
pnpm desktop:package
2
Android Native Client
Install the Android APK on your phone for native E2EE chat, push notifications (FCM), voice calls, and gallery media saving.
# Or build the debug APK with JDK 21:
cd apps/android && ./gradlew assembleDebug
3
Connect & Sign In
Open the app, choose your deployment server URL (or use default), and register or sign in with Google/GitHub/password.
