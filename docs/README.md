# BetweenUs docs

Docusaurus site for BetweenUs's architecture, system design, database
schema, service reference and deployment docs.

```bash
npm install
npm start        # http://localhost:3000
npm run build     # static site -> build/
```

Deployed to GitHub Pages by `.github/workflows/docs.yml` on any `master`
commit whose subject starts with `!docs`. See `/deployment/docs-deployment`
in the built site, or `docs/deployment/docs-deployment.md` here.
