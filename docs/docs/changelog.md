# Changelog

Generated automatically by the release pipeline (see
[Release Pipeline](/deployment/release-pipeline)) — every entry is written
into `CHANGELOG.md` at the repo root by
[`scripts/release-notes.mjs`](https://github.com/aiyu-ayaan/Nexora/blob/master/scripts/release-notes.mjs)
as part of the release PR, so it's reviewable before it ships and it's the
same text a GitHub Release shows.

The current, authoritative changelog lives at
[`CHANGELOG.md`](https://github.com/aiyu-ayaan/Nexora/blob/master/CHANGELOG.md)
and isn't duplicated here — this page would only ever be as fresh as the
last `!docs` build, and a stale changelog is worse than a link to the real
one. Releases: [github.com/aiyu-ayaan/Nexora/releases](https://github.com/aiyu-ayaan/Nexora/releases).
