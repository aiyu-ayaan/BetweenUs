# Brag Plan: BetweenUs

## What is this app?
BetweenUs is a unified, high-performance secure collaboration workspace featuring true AES-256-GCM end-to-end encrypted messaging, zero-media-server WebRTC P2P voice and video, synchronized YouTube listening, interactive in-call board games, 24-hour ephemeral Moments, and outbound remote desktop management.

## The angle
"Zero Media Server Infrastructure. Communication Without Compromise."
Unlike Discord, Slack, or Teams that decrypt, route, and store voice and video streams on centralized servers, BetweenUs creates an uninterceptable device-to-device WebRTC mesh where media never touches a relay server and text is sealed with client-held keys. We prove that uncompromising privacy and rich interactive social features (music sync, Carrom physics gaming, outbound remote desktop) can coexist seamlessly in a polished, modern workbench.

- **Direct WebRTC P2P Voice & Video Mesh:** 4-peer video grid with radiant emerald speaker halos (`#3fd68c`), live sub-20ms DTLS-SRTP latency HUD, and direct screen sharing.

## User flow worth showing
The core user journey from initial cryptographic verification through real-time communication to deep collaborative engagement:
1. **Entry & Trust Verification (0.0s – 4.0s):** Establishing client-side identity and zero-trust protocol (`AES-256-GCM sealed`).
2. **Asynchronous & Synchronous Chat (4.0s – 9.0s):** Sending verified code snippets and reacting with floating spring reactions in the workbench.
3. **P2P Audio/Video Mesh (9.0s – 14.0s):** Direct peer mesh call without server transcoding, showing real-time speaker audio detection (`18ms latency`).
4. **Shared Experience (14.0s – 19.5s):** Synchronized music listening with automatic voice ducking + in-call Carrom board physics.
5. **Private Media & Systems Control (19.5s – 25.0s):** Viewing an encrypted 24h story moment followed by launching an outbound remote desktop administration session.
6. **Unified Ecosystem (25.0s – 29.5s):** Seamless convergence across desktop and mobile clients.
